# Kitty Terminal — требования для конфигурации другого терминала

## Тема
- **Catppuccin Mocha** — тёмная пастельная тема
- фон: `#1E1E2E`, текст: `#CDD6F4`
- выделение: `#F5E0DC`
- курсор: `#F5E0DC`
- активный таб: фиолетовый `#CBA6F7`
- цвета терминала (color0–color15) — приглушённые пастельные

## Шрифт
- **JetBrains Mono**
- Размер: **11.5pt**

## Прозрачность фона
- `background_opacity 0.9` — фон чуть прозрачный

## Заголовок окна
- `hide_window_decorations yes` — убрать всё: заголовок, рамки, скругления

## Выделение текста
- `copy_on_select yes` — авто-копирование в буфер при выделении мышкой

## macOS
- `macos_option_as_alt left` — левый Option работает как Alt

## Хоткеи
| Хоткей | Действие |
|---|---|
| `Cmd+Right` | следующий таб |
| `Cmd+Left` | предыдущий таб |
| `Cmd+H` | скрыть окно |

## Цвета для встроенного diff
- фон: `#282a36`
- удалённые строки: красный `#ff5555`
- добавленные строки: зелёный `#50fa7b`
- поиск: голубой `#8be9fd`
- выделение: жёлтый `#f1fa8c`
